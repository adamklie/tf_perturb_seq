# Working groups — 2026 UTSW jamboree

One folder per working group. Each folder's `README.md` is a short overview a WG lead can point participants at on day 1: scope, lead questions, which datasets are usable, known issues, and where deliverables go.

Each WG owns a Synapse folder under [`syn74954078`](https://www.synapse.org/Synapse:syn74954078) (the mirrored `working_groups/` root) for uploading slides, draft figures, and other deliverables produced during the jamboree. Per-WG syn IDs are linked in each WG's README.

| 1 | [`wg1_data_qc/`](wg1_data_qc/) | Topic 1 / Fig 1 | Guide detection and repression; transcriptome-wide significance; cross-lineage shared TFs; trans-target overlap; technical harmonization |
