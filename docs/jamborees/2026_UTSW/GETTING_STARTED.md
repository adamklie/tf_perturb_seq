# Getting started — 2026 UTSW jamboree

A 5-minute orientation for participants. Read [`README.md`](README.md) for the full layout; this doc is the on-ramp.

## What you have

For each of the 5 production datasets (Hon CM, Huangfu DE, Huangfu ESC, Gersbach Hep, Engreitz endothelial) we are packaging three outputs:

1. **CRISPR pipeline** — IGVF FG pipeline outputs: dashboard, inference MuData, perturbo cis/trans TSVs.
2. **cNMF** — gene programs at the group-selected k, plus a sweep-as-provenance layer.
3. **Energy distance** — per-target energy distances + permutation p-values.

Plus cross-dataset **reference data**: IGVF GTF, TF metadata, experimental metadata, guide library.

Everything lives on Synapse under [`syn64423137`](https://www.synapse.org/Synapse:syn64423137) → `2026_UTSW/`. Per-output schemas in [`schemas/`](schemas/) describe the file layout and column structure for everything that's there.

## What's where (live status)

The at-a-glance status matrix is the top of [`README.md`](README.md). The machine-readable map of every dataset × output → Synapse ID is [`synapse_paths.tsv`](synapse_paths.tsv).

Open issues / outstanding asks per blocker: [`issues/`](issues/) (one report per problem, ready to share with whoever owns the fix).

Per-dataset folders ([`datasets/<dataset>/`](datasets/)) each have a `README.md` summarizing what's on Synapse for that dataset, with deeper per-analysis READMEs in `crispr_pipeline/`, `cnmf/`, `energy_distance/` subdirs.

## Cross-dataset summaries (start here for WG1)

Two pre-computed roll-ups land in [`reference/`](reference/) — useful first stops for any cross-dataset comparison:

- [`reference/cross_dataset_pipeline_summary.tsv`](reference/cross_dataset_pipeline_summary.tsv) — one row per dataset with cell counts, gene/guide UMI medians, knockdown stats (intended_target AUROC/AUPRC), perturbo cis/trans significance counts. Generated by [`scripts/cross_dataset_pipeline_summary.py`](../../../scripts/cross_dataset_pipeline_summary.py).
- [`reference/cross_dataset_edistance_summary.tsv`](reference/cross_dataset_edistance_summary.tsv) — one row per dataset with target counts (by type), `distance_mean` medians (by type), and the **calibration-robust significance proxy** `n_targeting_above_nc_max` (use this instead of raw p-value-based counts; see [Issue 1](issues/edistance-calibration.md)). Generated by [`scripts/cross_dataset_edistance_summary.py`](../../../scripts/cross_dataset_edistance_summary.py).

## Authenticate to Synapse

You need a Synapse account + a personal access token. Set it once:

```bash
# Get a token from https://www.synapse.org/Profile:v/settings ("Personal Access Tokens")
export SYNAPSE_AUTH_TOKEN="<your-token>"
# Persist in ~/.zshrc or ~/.bashrc to avoid re-exporting
```

Then in Python:

```python
import synapseclient
syn = synapseclient.Synapse()
syn.login(authToken=os.environ["SYNAPSE_AUTH_TOKEN"], silent=True)
```

```python

# Guide library (14,150 guides × 18 cols, IGVF pools A-D)

```

## Load a dataset's CRISPR pipeline output

The canonical bundle is three folders: `pipeline_dashboard/`, `pipeline_info/`, `pipeline_outputs/`.

```python
# Huangfu DE example — Synapse syn74834952
# Download just the inference MuData (the typical entrypoint for downstream analysis)
mudata_handle = syn.get(
    "syn-id-of-inference_mudata.h5mu",  # find it via the children of syn74834952/pipeline_dashboard/
    downloadLocation="./",
)
import mudata as md
mdata = md.read_h5mu(mudata_handle.path)
print(mdata)              # gene + guide modalities + (sometimes) hashing
print(mdata.mod["gene"].shape)
```

For perturbo-based per-element / per-guide TSVs use the files under `pipeline_outputs/`. Schema: [`schemas/crispr_pipeline.json`](schemas/crispr_pipeline.json). Walkthrough: [`docs/analysis/CRISPR_PIPELINE_OUTPUTS.md`](../../analysis/CRISPR_PIPELINE_OUTPUTS.md).

## Load a dataset's energy distance output

```python
# Huangfu DE energy distance — Synapse syn74883327
# pval_edist_full.csv is the primary results file (one row per target, distance + permutation pvals)
pval_path = syn.get("syn-id-of-pval_edist_full.csv").path
ed = pd.read_csv(pval_path, index_col=0)
print(ed.shape)           # 2267 × 46 for Huangfu DE (steps 1+2 only; step 3 adds matrix + embedding)
print(ed.columns.tolist())
```

⚠ **Calibration concern (both Huangfu runs)**: p-values are anti-conservative — all 100 negative-control targets have `pval_mean=0`. Use raw `distance_mean` as effect size; **don't** threshold on `pval_mean` alone. Full diagnosis: [Issue 1](issues/edistance-calibration.md).

Schema: [`schemas/energy_distance.json`](schemas/energy_distance.json). Walkthrough: [`docs/analysis/ENERGY_DISTANCE_OUTPUTS.md`](../../analysis/ENERGY_DISTANCE_OUTPUTS.md).

## cNMF outputs (when they land)

Production cNMF runs are in flight (HTv2 testbed verifying first; Huangfu DE + ESC pre-staged on HPC, ready to launch). The bundle layout is documented in [`schemas/cnmf.json`](schemas/cnmf.json) and [`docs/analysis/cNMF_OUTPUTS.md`](../../analysis/cNMF_OUTPUTS.md). Two purposes:

1. **Selected-k full data** — integrated MuData + all loadings + cell usages + selected-k Eval/, Plot/, Annotation/, Interpretation/.
2. **Sweep-as-provenance** — `k_selection.png` + stats, all-k clustering pngs, all-k `gene_spectra_score`, all-k `Eval/` TXT bundles, `Plot/k_selection_*/`, `README.txt` with the selection rationale. Lets a future reader revisit the k decision without re-running.

## Working groups

Scientific scope: [`TOPICS.md`](TOPICS.md). Working group structure (5 + 1 working groups, each tied to a topic): [`WORKING_GROUPS.md`](WORKING_GROUPS.md).

The outputs above are shaped to answer the questions in those docs:

| Working group | Primary input |
|---|---|
| WG1 — Data summarization, pipeline, QC | CRISPR pipeline (`additional_qc/`), energy distance (`pval_edist_full.csv`), cNMF (cell usages) |
| WG2 — Gene program annotation across lineages | cNMF (`gene_spectra_score`, `Eval/` enrichment, perturbation associations) |
| WG3 — Disease & GWAS | TF metadata (Lambert + JASPAR), cNMF (trait enrichment) |
| WG4 — GRN inference | All three outputs + multiome data (separate) |
| WG5 — TF family case studies | Outputs from WG1-3 |
| WG6 (optional) — Predictive modeling | Cross-dataset cNMF + energy distance |

## When you hit a wall

- Schema unclear → open the JSON in [`schemas/`](schemas/); it lists every column with type + source notes.
- File doesn't match the schema → check the dataset's per-analysis `README.md` for documented deviations / known caveats.
- Something's missing on Synapse → check [`issues/README.md`](issues/README.md); it's probably tracked there with whose-ball attribution.
- Need to mirror a new output to Synapse → use the corresponding `scripts/mirror_*.py`. They're idempotent and update `synapse_paths.tsv`.
